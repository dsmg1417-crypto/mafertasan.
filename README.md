# MAFERTASAN Gestión en Salud

Sitio web estático preparado para publicar en Vercel. No requiere instalación ni compilación: `index.html` es la portada y las páginas HTML de la carpeta contienen información detallada por servicio.

## Contenido

- Portada con navegación por secciones, formulario que prepara una consulta para WhatsApp y precios agrupados.
- Páginas informativas para gestión de salud, derechos de petición, tutelas, reclamaciones EPS, trámites digitales y servicios empresariales.
- Aviso de privacidad y condiciones del servicio en versión preliminar para revisión del negocio.
- Diseño adaptable a móvil y escritorio; imágenes y estilos están en `assets`.

## Publicación

Importa en Vercel el repositorio de GitHub que contiene esta carpeta, o sube estos archivos al repositorio conectado. Configuración: framework **Other**, directorio raíz donde está este `README.md` e `index.html`, y sin comando de compilación. `vercel.json` activa URLs limpias.

## Antes de publicar

Confirma que el teléfono, precios, área de atención y condiciones de pago sigan vigentes. La política de privacidad y las condiciones son borradores informativos: el responsable debe completarlos/revisarlos, en particular identificación legal y plazos de conservación de datos. No se incluyen testimonios ficticios ni dirección exacta porque no se proporcionaron datos verificables.

La configuración de Perfil de Empresa de Google, Search Console, redes sociales, reseñas y anuncios requiere acceso y decisiones del titular del negocio; no se inventaron perfiles ni presupuestos.
